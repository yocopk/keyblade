# Trademark and branding policy

**The AGPL-3.0 licence covers the source code of Keyblade. It does not grant any
right to the project's name, logo or visual identity.**

This distinction is deliberate and it matters: the code is free, the identity is
not. Without it, anyone could ship a modified, backdoored build and still call it
"Keyblade" -- which for a program that guards secrets would be a security problem,
not just a branding one.

## Reserved

The following are reserved by the copyright holder and are **not** covered by the
AGPL grant:

- the name **Keyblade**, alone or as part of a compound name
- the Keyblade logo and application icon
- the stained-glass sigil mark
- the overall visual identity: colour palette, typography and interface look as
  applied to the branded product

## What you may do without asking

- Use, study, modify and redistribute the source code under the AGPL-3.0.
- State factually that your software "is based on Keyblade", "is a fork of
  Keyblade" or "is compatible with Keyblade", provided the statement is accurate
  and does not suggest endorsement.
- Use the name in articles, reviews, tutorials, academic work and comparisons.
- Reproduce the logo when writing *about* the project (nominative use).

## What requires written permission

- Distributing a modified build under the name **Keyblade**.
- Naming a product, service, company, domain or app-store listing in a way likely
  to be confused with Keyblade.
- Using the logo or visual identity as the branding of your own product.
- Suggesting, by any means, that a fork is official or endorsed.

## If you fork

You are welcome to. **Change the name and the icon.** Keep the copyright notices
and the AGPL, as the licence requires, and remove the Keyblade branding. Nobody
should be able to install your build believing it is this one.
